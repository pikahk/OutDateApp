# outDate

Приложение для Android, которое следит за сроками годности продуктов, лекарств и косметики, а заодно напоминает о списаниях по платным подпискам.

Добавляешь продукт, указываешь дату с упаковки, и приложение показывает, сколько дней осталось, и заранее присылает уведомление. Если открыл упаковку, нажимаешь «Открыть сегодня», и срок пересчитывается с учётом того, сколько продукт хранится после вскрытия. Например, сметана годна месяц, но после вскрытия всего три дня.

## Что умеет

- считает срок годности по дате с упаковки или по дате изготовления и сроку хранения;
- учитывает срок после вскрытия;
- заполняет название и категорию по штрихкоду и распознаёт дату с упаковки камерой;
- запоминает товары, которые уже добавлялись, и при следующем сканировании подставляет их сам;
- присылает уведомления о сроках и о списаниях по подпискам;
- ведёт подписки и показывает, сколько на них уходит в месяц;
- позволяет вести общий список продуктов с семьёй;
- синхронизирует данные между телефонами после входа в аккаунт, а без аккаунта работает только на телефоне.
