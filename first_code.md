# Первый показ кода

Создан проект Android-приложения OutDate на Kotlin с интерфейсом на Jetpack Compose. Настроены система сборки Gradle, автоматическая проверка стиля кода (ktlint) и сборка с запуском тестов на GitHub Actions при каждом изменении.

Реализовано:

- локальная база данных Room с таблицами расходников и категорий;
- расчёт оставшегося срока годности с учётом срока после вскрытия, покрытый модульными тестами;
- главный экран со списком расходников и цветовой отметкой срочности;
- Сценарий 2 «Добавление расходника вручную»: форма с названием, категорией, сроком годности (датой «годен до» или датой изготовления и сроком хранения) и сроком после вскрытия;
- Сценарий 5 «Вскрытие расходника»: карточка расходника, кнопка «Открыть сегодня» с пересчётом оставшегося срока, отмена вскрытия и удаление.
